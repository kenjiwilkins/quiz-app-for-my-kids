# なにかな?クイズ

3歳くらいの子ども向けの、画像あてクイズ Web アプリです。
ジャンル（くだもの・どうぶつ など）を選ぶと、そのジャンルの画像がシャッフルされて1枚ずつ出てきます。
画像をタップすると答えが大きく表示され、読み上げられます。

- Vite + React + TypeScript、CSS Modules
- バックエンド・ログイン・外部通信・分析ツールはありません
- PWA 対応（ホーム画面に追加でき、オフラインでも動きます）
- 見た目は bow-house デザインシステム（四角・太い線・赤 / 青 / 黄）に合わせています。フォントは外部から読み込まず、端末の日本語フォントを使います

## 使い方（開発）

```bash
pnpm install
```

```bash
pnpm dev
```

| コマンド | 内容 |
| --- | --- |
| `pnpm dev` | 開発サーバーを起動（http://localhost:5173） |
| `pnpm build` | 型チェック + 本番ビルド（`dist/` に出力） |
| `pnpm preview` | ビルド結果をローカルで確認（PWA の動作確認はこちらで） |
| `pnpm lint` | ESLint |
| `pnpm typecheck` | TypeScript の型チェックのみ |
| `pnpm images:check` | クイズ画像がすべて WebP・長辺 1200px 以内・400KB 以内か確認 |
| `pnpm images:optimize` | クイズ画像を WebP（長辺 1200px 以内）に変換して置き換え。credits.json のキーも書き換える |
| `pnpm audio:check` | 読み上げ音声がすべて `.m4a`・100KB 以内で、ファイル名が答えと一致しているか確認 |
| `pnpm voice:generate` | ローカルの VOICEVOX で、音声がまだない問題の読み上げ音声（.m4a）を作る（下の「読み上げ音声」を参照） |
| `pnpm audio:optimize` | 読み上げ音声（WAV など）をモノラル・AAC 48kbps の `.m4a` に変換して置き換え（macOS の `afconvert` を使う） |

画像は JPG / PNG のまま置いてかまいません。コミット前に `pnpm images:optimize` を実行してください（Claude Code でコミットするときは、`.claude/settings.json` のフックが自動でチェックし、WebP 化されていなければコミット・プッシュを止めます）。

## ジャンルの追加方法

`src/assets/quiz/` の下にフォルダを作るだけです。**フォルダ名がそのままジャンル名**になります。

```
src/assets/quiz/
├─ くだもの/
├─ どうぶつ/
└─ のりもの/      ← フォルダを作って画像を入れると「のりもの」ジャンルが増える
```

- ジャンル名はひらがなにしてください（子どもが読むため）
- ジャンルの並び順はあいうえお順です
- ジャンル選択画面のカード画像には、そのフォルダの **`default`** という名前の画像（例: `default.webp`）が使われます。`default` は出題されません
- `default` がないときは、あいうえお順で最初の画像がカードに使われます
- 出題する画像が1枚もないフォルダ（`default` だけのフォルダなど）は表示されません
- コードの変更は不要です

## 画像の追加方法

ジャンルのフォルダに画像を置くだけです。**ファイル名（拡張子を除く）がそのまま答え**になり、表示と読み上げに使われます。

```
src/assets/quiz/くだもの/りんご.webp   → 答えは「りんご」
```

- 対応形式: `.png` `.jpg` `.jpeg` `.webp`（おすすめは `.webp`）
- ファイル名はひらがなにしてください
- 正方形に近い画像がきれいに見えます（サムネイルは正方形に切り抜かれます。クイズ画面では全体が表示されます）
- 1枚あたり 200KB 程度までにしておくと、読み込みが速く、オフライン用のキャッシュも軽くなります
- 画像は `import.meta.glob` で自動的に集められるので、コードの変更は不要です
- 開発サーバーの起動中に追加した場合は、ブラウザを再読み込みしてください

いま入っている画像（`くだもの/` と `どうぶつ/` の `.png`）は動作確認用のダミーです。本物の画像に差し替えて、ダミーは削除してください。

## 色のクイズ（画像なし）

色の問題は画像を置かずに、ジャンルのフォルダに `colors.json` を置いて Hex で書きます。

```
src/assets/quiz/いろ/colors.json
```

```json
{
  "あか": "#E53935",
  "あお": "#1E63D6",
  "しろ": "#FFFFFF"
}
```

- **キーがそのまま答え**になり、表示と読み上げに使われます（ひらがなで書いてください）
- 色は `#RRGGBB`（または `#RGB`）で書きます。書き間違いがあると、開発サーバーのブラウザのコンソールに警告が出て、その色は出題されません
- クイズ画面では、その色で塗った図形（四角→丸→三角）が出ます
- ジャンル選択のカードは、`default` の画像がなければ先頭の4色の図形で自動的に描かれます
- 同じフォルダに画像と `colors.json` を一緒に置くこともできます
- 色の問題はクレジット一覧には載りません。`images:check` / `images:optimize` の対象にもなりません
- 3歳の子が迷いやすい組み合わせ（オレンジとちゃいろ、むらさきとあお など）は、慣れてから足すのがおすすめです

## 文字のクイズ（画像なし）

ひらがな などの文字の問題も、画像を置かずにジャンルのフォルダに `text.json` を置いて書きます。

```
src/assets/quiz/ひらがな/text.json
```

```json
{
  "pick": 20,
  "items": ["あ", "い", "う", "え", "お"]
}
```

- `items` の文字が、そのまま問題と答えになります。クイズ画面に文字が大きく出て、答えを出すと読み上げます
- `にゅ` `きゃ` のように2文字以上でもかまいません（枠に収まる大きさで表示されます）
- 読み方を決めたいときは、文字列の代わりに `{ "text": "a", "read": "エー" }` と書きます。`read`（カタカナがおすすめ）が読み上げられます。英字1文字などは、そのままだと日本語の読み上げで読み方がぶれるためです
- `pick` は1回のクイズで出す数です。`items` からランダムに選ばれ、「もういっかい」のたびに選び直します。書かなければすべて出題します
- ジャンル選択のカードには `items` の先頭の文字が出ます
- いまは `ひらがな`（清音 46文字）と `ひらがな２`（濁音・半濁音と、きゃ などの拗音 58個）があり、どちらも 20個ずつ出題します
- `"lang": "en-US"` を書くと、そのジャンルは英語の声で読み上げます（書かなければ日本語）
- `えいご`（大文字 A〜Z）と `えいご２`（小文字 a〜z）は `pick` なしで 26文字すべてを出題し、英語で読み上げます。小文字は、英語の声だと `a` が単語の「ア」と読まれることがあるので、`read` に大文字を書いています
- 文字の問題もクレジット一覧には載らず、`images:check` / `images:optimize` の対象にもなりません

## 読み上げ音声（任意）

答えの読み上げは、ふだんは端末の Web Speech API を使います。読みやイントネーションを正しくしたい問題だけ、自分で作った音声（VOICEVOX など）を置けます。**音声がある問題はその音声を鳴らし、ない問題は今までどおり Web Speech API で読み上げます。**

```
src/assets/quiz/しんかんせん/100系.wav   → 「100系」の問題で鳴らす
src/assets/quiz/ひらがな/あ.wav          → text.json の「あ」で鳴らす（read ではなく文字そのものの名前）
src/assets/quiz/いろ/あか.wav            → colors.json の「あか」で鳴らす
src/assets/voice/おしまい.wav            → おしまい画面で鳴らす
```

- ファイル名（拡張子を除く）を、そのジャンルの答えと同じにしてください。一致しないと `audio:check` が失敗します
- WAV のまま置いてかまいません。コミット前に `pnpm audio:optimize` で `.m4a` に変換されます（WAV は `.gitignore` 済み）。フックは未変換の音声があるとコミット・プッシュを止めます
- 音声は `<audio>` ではなく Web Audio API で鳴らすので、スマホのロック画面や通知に「再生中」が出ず、ほかのアプリの音楽も止めません。iPhone のマナーモード中は鳴りません
### VOICEVOX でまとめて作る（`pnpm voice:generate`）

VOICEVOX のデスクトップアプリを起動しておくと、裏で動くエンジン（`http://127.0.0.1:50021`）を使って、コマンドから音声を作れます。声は ずんだもん（ノーマル）、話し方はアプリの既定値と同じです（`scripts/generate-voice.mjs` の `CONFIG` で変えられます）。

```bash
pnpm voice:generate --dry-run              # 作らずに、読みとアクセントだけ確認する
pnpm voice:generate                        # 音声がまだない問題をすべて作る
pnpm voice:generate --genre でんしゃ         # ジャンルをしぼる
pnpm voice:generate --only 常磐線 --force    # 決めた問題だけ作り直す
```

- すでに音声がある問題（アプリで手作りしたものを含む）は、`--force` を付けない限り上書きしません
- 「す」などが息だけの音（無声化）にならないよう、はっきり発音させます
- 英語のジャンル（`lang` があるもの）は作りません
- 読みやアクセントがおかしいときは、ジャンルフォルダの `voice.json` に書いて作り直します

```json
{
  "JR大和路線": "ジェイアールヤマトジセン",
  "阪堺電車": "ハンカイデ'ンシャ"
}
```

  - `'` を含まない値は、ふつうの文として読ませます（カタカナで読みを決める）
  - `'` を含む値は、アクセントつきのカナ表記です。`'` の直前の音が高く、そこから下がります。`/` でアクセント句を区切り、長音は `ー` ではなく母音で書きます（例: `ジョオバンセン'`）。`--dry-run` に出るカナ表記を写して直すと楽です
  - 「おしまい」は `src/assets/voice/voice.json` に書きます
  - `voice.json` のキーが答えと一致しないと `audio:check` が失敗します

- VOICEVOX の声を使うときは、利用規約に従ってクレジット（例: `VOICEVOX:ずんだもん`）を表記してください。クレジット画面の表記は `src/lib/credits.ts` の `voiceCredits` に書きます（別の声を使ったら追加する）

## クレジットの書き方

Wikipedia / Wikimedia Commons の画像には、ライセンス（CC BY-SA など）にもとづく表示義務があります。
`src/assets/quiz/credits.json` に、画像ごとの作者・ライセンス・出典 URL を書いてください。
ジャンル選択画面の下の「がぞうについて」から、保護者向けのクレジット一覧で確認できます。

```json
{
  "りんご.webp": {
    "author": "Taro Yamada",
    "license": "CC BY-SA 4.0",
    "sourceUrl": "https://commons.wikimedia.org/wiki/File:Example.jpg"
  },
  "くだもの/みかん.webp": {
    "author": "Hanako Suzuki",
    "license": "CC BY 2.0",
    "sourceUrl": "https://commons.wikimedia.org/wiki/File:Example2.jpg"
  }
}
```

- キーは**拡張子つきのファイル名**です（例: `りんご.webp`）
- `default` の画像はどのジャンルにもあるので、`くだもの/default.webp` のように**ジャンル名つき**で書いてください
- 同じファイル名の画像が別のジャンルにもある場合は、`ジャンル名/ファイル名`（例: `くだもの/みかん.webp`）で書けます。こちらが優先されます
- `author`（作者）、`license`（ライセンス名）、`sourceUrl`（Commons のファイルページの URL）を書きます
- Commons のファイルページの「このファイルを再利用する」（Use this file）に、作者とライセンスの表記がまとまっています
- credits.json に書かれていない画像があると、**開発サーバー（`pnpm dev`）のブラウザのコンソール**に警告が出ます。ビルドは止まりません

## デプロイ（Vercel）

Vercel にリポジトリをつなぐだけで、自動で `pnpm build` され `dist/` が公開されます。`vercel.json` は不要です。
（Framework Preset は「Vite」が自動で選ばれます）

## ファイル構成

```
src/
├─ App.tsx                 画面の切り替え（ルーティングライブラリは使わない）
├─ components/
│   ├─ GenreSelect.tsx     ジャンル選択画面
│   ├─ Quiz.tsx            クイズ画面
│   ├─ Result.tsx          おしまい画面
│   ├─ Credits.tsx         画像クレジット一覧（保護者向け）
│   ├─ ColorShape.tsx      色の問題の図形とカード
│   ├─ Button.tsx / HomeButton.tsx / Shapes.tsx
├─ lib/
│   ├─ loadAssets.ts       画像・colors.json・text.json の自動収集
│   ├─ colors.ts           ジャンルの色と図形の順番
│   ├─ shuffle.ts          Fisher-Yates シャッフル（純粋関数）
│   ├─ credits.ts          クレジットの照合と開発時の警告
│   ├─ speak.ts            読み上げ（Web Speech API、非対応なら何もしない）
│   └─ preload.ts          次の画像の先読み
├─ styles/global.css       デザイントークンと共通スタイル
└─ assets/quiz/            クイズ画像・colors.json・text.json と credits.json
public/                    PWA アイコン
```
